A turn, start to finish

“If I prepay ₹50,000 today, how much interest would I save?”

1 · open

Stream opens

The customer id comes from the signed token, never from the model, so no prompt can point a tool at someone else's records.

status line in < 5 ms
2 · plan

Planner picks tools

Claude streams with tool schemas generated from the active packs. Without a model, regex intents from the same packs pick the same tools.

first token p50 2.0 s (Haiku 5.5)
3 · fetch

Systems in parallel

One composite tool reads the loan and schedule, asks the policy engine about charges, and runs the prepayment calculator in Decimal.

~6 system calls, most from cache
4 · check

Every number verified

Each figure in the reply must appear in this turn's tool output. In voice, a sentence is spoken only after it passes.

₹22,883 saved · 4 fewer EMIs
5 · act

Request on approval

The model only proposes. The executor freezes the parameters, asks for a one-time code, files once and writes an append-only audit row.

idempotent, audited
Swappable modules

Every module can move to a cloud service or our own hardware

Each one sits behind a small interface and is chosen by configuration. The calculators, policy engine, grounding check and action executor stay fixed in code with tests, because they are what the product guarantees.

Production path

What changes between this and 1,000 live conversations

State out of the processSessions in Redis and audit in Postgres: both already selectable by URL. Then orchestrator replicas behind a load balancer.
Voice on telephonySIP or WebRTC workers call the same turn API with channel voice; speech on a batched GPU pool or a managed service.
Model capacity and routingRate limits sized for ~5,000 requests a minute, failover to a second model, small models for fillers, caching tuned from recorded spans.
Systems of recordReal CRM, loan and payment APIs behind the same gateway, with per-system concurrency agreed with their owners; writes through a queue.
SecurityReal OTP over SMS, RS256 tokens with refresh, secrets in a vault. The API already refuses to start outside demo mode with development secrets.
ObservabilitySpans already carry OpenTelemetry names; export them to a collector and alert on first-token latency and grounding replacements.
